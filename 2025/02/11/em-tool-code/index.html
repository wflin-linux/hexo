常用linux指令

发表于 2025-02-12 更新于 2025-03-24 分类于 linux command

指令类

pkill

  • 用于杀死进程和 kill 指令不同的是它可以直接通过进程的名字，而不需要进程的pid
  • pkill appName

watch

  • 它的作用是定期执行并显示另一个命令或脚本的输出变化，例如：它可以用于持续监控系统的负载情况。

  • 举例

iptabels

  • iptables 是Linux内核中自带的防火墙，用于在网络数据包层 4（传输控制协议 TCP 和用户 datagram 协议 UDP）级别进行过滤和 NAT 等网络配置和管理。它提供了一种高度灵活、模块化且功能强大的方式来设置系统级别的防火墙规则

转发端口

  • 有一个ip摄像头（192.168.8.243）连接在一块开发板上并接入了内网（172.16.19.146）,摄像头有一个80的web后台服务。内网无法直接访问到摄像头的地址，现在需要通过 iptables 配置端口转发将相机的后台服务转发到内网的80端口上，我们就能通过 172.16.19.146:80 对开发板中相机服务进行访问

tcpdump

  • 是一个广泛使用的网络协议分析工具（也称为数据包捕获工具），可以用来捕获并显示计算机在局域网上传输的数据包。它通常用于故障排除、网络分析或安全监测等活动
